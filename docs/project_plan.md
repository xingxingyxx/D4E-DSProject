# 巴黎 Airbnb 房东收益预测：项目计划

2026-11-10 · Sigrid

## 目标与研究问题

做一个工具：输入巴黎一套房源（地址、房型、卧室数、可住人数），输出**未来 12 个月的短租收入区间**、**投资收益率**，并和**长租收益**对比。

三个研究问题：

1. 房源特征、位置、周边环境和季节因素各自解释了多少收入差异？
2. 在巴黎的出租天数限制下，短租相比长租在哪些区、哪类房源上仍然更划算？
3. （可选）结合房东退出风险：预期回报 = 每年预期收入 × 房东继续经营的概率。

预期交付：分析报告 + 一个可交互的收益估算小应用（Streamlit）。

## 数据与合并方案

以 Inside Airbnb 的房源为主表，其他六个来源按坐标、街区或日期接入。

| 数据 | 来源 | 用途 | 合并键 | 优先级 |
| --- | --- | --- | --- | --- |
| listings.csv.gz（详细版） | [Inside Airbnb](https://insideairbnb.com/get-the-data/) | 房源特征、价格、评分、房东信息 | 主表（房源 ID） | 第一步必须 |
| reviews.csv.gz | Inside Airbnb | 按月评论数 → 入住估算与季节性 | 房源 ID + 日期 | 第一步必须 |
| calendar.csv.gz | Inside Airbnb | 未来 365 天可订状态、最少入住晚数 | 房源 ID + 日期 | 可选 |
| 房产成交价 DVF | [data.gouv.fr](https://www.data.gouv.fr/fr/datasets/5c4ae55a634f4117716d5656/) | 每平米买入价格 | 坐标 / 区 | 第二步 |
| 参考租金（租金管制） | opendata.paris.fr | 长租收入基准 | 街区 + 房间数 | 第二步 |
| INSEE IRIS 收入与人口 | INSEE | 周边社会经济环境 | 坐标 → IRIS | 第三步 |
| 地铁站、景点、餐厅 | OpenStreetMap | 交通与旅游便利度（距离、密度） | 坐标 | 第三步 |
| 历史天气 | Open-Meteo / Meteostat | 月度气温、降雨 | 月份 | 第三步 |
| 节假日与大型事件 | Python `holidays` 库、手工整理（时装周、展会、2024 奥运会） | 需求高峰 | 日期 / 月份 | 第三步 |

Inside Airbnb 只免费提供最近 12 个月的季度快照，但评论文件包含房源全部历史评论，所以单一快照也能得到多年的月度活动序列。数据不得转载，需注明出处。

## 收入估算方法

Inside Airbnb 没有真实预订，收入用其公布的“旧金山模型”从评论反推，再受巴黎出租天数上限约束。

```math
\text{nights}_{12m} = \min\left( \frac{\text{reviews}_{12m}}{r} \times \max(L,\ \text{min nights}),\ 0.7 \times 365,\ C \right)
```

```math
\text{Revenue}_{12m} = \text{nights}_{12m} \times \text{ADR}
```

| 参数 | 基准值 | 敏感性范围 | 依据 |
| --- | --- | --- | --- |
| r 评论率 | 50% | 30%–72% | [Inside Airbnb 假设](https://insideairbnb.com/data-assumptions/) |
| L 平均入住晚数 | 5.2 晚（由巴黎数据中 Inside Airbnb 的入住估算反推；其通用默认为 3 晚） | 3 晚（保守） | 同上 |
| 入住率上限 | 70% | — | 同上 |
| C 合规上限 | 主要住所 90 晚/年 | 不设上限（对照组） | [Paris.fr](https://www.paris.fr/pages/location-limitee-a-90-jours-paris-serre-la-vis-sur-les-meubles-touristiques-29653) |
| ADR 平均每晚价格 | listings 的当前标价 | ± 季节性调整 | listings / calendar |

全部结果至少在 r = 30%、50%、72% 三种情景下报告。标价不等于成交价，这是另一个向上偏差来源。

## 模型设计

收入拆成“价格 × 入住晚数”两个子模型，分别可解释、可检验。

1. **清洗**：只保留整套房源；去掉价格缺失或极端（如 >1,000 欧/晚）、过去 12 个月无评论的房源；价格取对数
2. **价格模型**：特征 = 可住人数、卧室/床/卫生间数、房型、区、到市中心距离、评分、超赞房东、房东房源数、最少入住晚数；先做线性特征价格回归作为可解释基准，再用梯度提升树
3. **入住模型**：目标 = 估算的未来 12 个月入住晚数；特征同上，加历史评论密度和月度季节指数
4. **时间切分验证**：用截止日前的数据建特征，预测截止日后 12 个月的评论活动，避免信息泄露
5. **冷启动**：新房源无历史评论，用 500 米内、相同卧室数的可比房源（kNN）中位数推算
6. **区间预测**：分位数回归输出 P10 / P50 / P90，而不是单一数字
7. **解释**：特征重要性与置换重要性，回答“位置 vs 房源本身”各占多少

评估指标：价格用 MAE（欧元）和 R²；入住与收入用 MAE 和分位数覆盖率（P10–P90 区间是否包含约 80% 的实际值）。

## 投资回报与合规

自 2025 年 1 月 1 日起，巴黎主要住所短租上限从 120 晚降到 **90 晚/年**（[Paris.fr](https://www.paris.fr/pages/location-limitee-a-90-jours-paris-serre-la-vis-sur-les-meubles-touristiques-29653)），所以收益率必须按合规情景分开算。

```math
\text{Net yield} = \frac{\text{Revenue}_{12m} \times (1 - f) - \text{cleaning} - \text{charges}}{\text{price per m}^2_{\text{DVF}} \times \text{surface}}
```

| 情景 | 可出租晚数 | 说明 |
| --- | --- | --- |
| A 主要住所，合规 | ≤ 90 晚 | 最贴近普通房东的现实 |
| B 不设上限 | 模型估算值 | 对照组，衡量监管的收入成本 |
| C 长租 | 12 个月 | 参考租金 × 面积，作为基准 |

待定参数（先用假设值，报告中标明）：

- f 平台服务费率、清洁成本、物业费与税费
- 面积：Airbnb 面积字段多为空，按卧室数与可住人数估算
- 买入价格：按房源所在区 DVF 成交价中位数 × 面积，无法与单套房源一一对应
- 二套房短租需要变更用途许可，实际可行性很低，写报告前需再核实具体规定

## 初步结果

基于 2026 年 9 月 24 日的巴黎快照，一套活跃的整套房源过去 12 个月的估算短租收入中位数约 **21,400 欧元**；按 90 晚上限计算降到约 **14,700 欧元**。这是估算值，对假设很敏感（见下表）。

**样本**：77,149 个房源 → 整套房源 68,333 → 有价格 38,131 → 价格在 20–1,000 欧 36,715 → 最少入住少于 30 晚 31,047 → 截止日（2025-09-24）前已有评论 **21,100**。用截止日前的信息预测之后 12 个月。

**模型表现**（20% 测试集，4,220 个房源）：

| 模型 | 指标 | 模型 | 朴素基准（沿用上一年） |
| --- | --- | --- | --- |
| 收入，不设上限（情景 B） | MAE | 10,319 欧 | 12,878 欧 |
| 收入，不设上限（情景 B） | 排序相关（Spearman） | 0.86 | 0.78 |
| 收入，不设上限（情景 B） | P10–P90 区间覆盖率 | 85%（目标 80%） | — |
| 收入，90 晚上限（情景 A） | MAE | 5,789 欧 | 4,463 欧 |
| 每晚价格 | MAE / R²（对数） | 73 欧 / 0.64 | — |

情景 B 的模型比朴素基准误差低约 20%。**情景 A 的模型不如朴素基准**：一半房源顶到 90 晚上限，直接预测收入不合适，下一版应先预测入住晚数再套上限。

**其他发现**：

- 对已有历史的房源，决定未来收入的首先是**上一年的评论量**，其次是价格、评分、超赞房东；知道历史后，区位几乎不再增加信息。区位的作用体现在价格上（价格模型 R² 0.64），对新房源的冷启动更重要
- 季节性明显：6 月评论量是月均的 1.38 倍，2 月只有 0.68 倍
- 16% 的房源在目标年度没有任何评论，即疑似停止经营，这是接入“房东退出”生存分析的入口

**读数时要注意**：价格字段是 2026 年秋季某个入住日期的报价，中位数 242 欧/晚，可能高于全年平均成交价；样本只含仍有报价的活跃房源，存在幸存者偏差；估算超过 90 晚不等于违规，其中包含已变更用途的商业房源。

## 局限与下一步

局限：

- 收入是从评论反推的估算值，没有真实标签，模型本质上在预测“估算的估算”
- 价格、评分等房源字段取自快照当天，而非截止日，存在轻微的信息泄露；用两个季度快照可以修正
- 标价不等于成交价，收入偏高
- 买入价格只能按区级平均估算
